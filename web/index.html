Interpretation and limitations

This tool analyzes residue geometry. It does not predict protein folding, implement Invariant Point Attention, or infer 3D structures from sequences. Secondary structure uses simple angle thresholds with run-length smoothing. N–O distance pairs are not physical hydrogen-bond assignments. Contacts include local sequence neighbors.

Files stay in this browser session and are not uploaded by this app. A Python runtime is downloaded from a third-party CDN. Browser analysis is capped at 1,000 residues.
